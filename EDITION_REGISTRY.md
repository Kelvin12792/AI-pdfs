# EDITION_REGISTRY.md — Edition Registry

## How to Use This File

Every edition must be registered here the moment it is created. Update the status field at each stage. Never delete a row — if an edition is cancelled, mark it `[CANCELLED]` with a note.

**Status tags:**
- `[PLANNED]` — title and topic assigned, no draft started
- `[DRAFTED]` — draft complete, not yet reviewed
- `[APPROVED]` — draft approved, assets not yet built
- `[ASSETS READY]` — all images and diagrams complete
- `[BUILT]` — PDF exported and QA passed
- `[PUBLISHED]` — live on all distribution channels
- `[CANCELLED]` — will not be produced (with reason)
