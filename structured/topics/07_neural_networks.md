### Research-Based Additions (Claude Knowledge)

- **What a neural network is:** A series of mathematical layers that process information. Data enters one end, passes through multiple layers (each one refining the understanding), and a result comes out the other end. Loosely inspired by how neurons in the brain pass signals.
- **Layers explained simply:** Input layer (receives the data), hidden layers (where the actual learning happens — each layer extracts increasingly complex patterns), output layer (produces the answer). A network with many hidden layers is called "deep" — this is where "deep learning" gets its name.
- **How neurons work (simplified):** Each artificial neuron receives numbers, multiplies them by weights (importance), adds them up, and passes the result forward if it crosses a threshold. Like a vote — if enough evidence points one way, the signal moves forward.
- **Why depth matters:** Early layers detect simple patterns (edges in an image, common word pairs). Deeper layers combine simple patterns into complex ones (faces, sentences, meanings). It is like going from seeing individual LEGO bricks to seeing the completed castle.
